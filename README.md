# Mastermind-Game_UI

This is a frontend part of Mastermind game project. The Mastermind game is very nice game where you have to guess the generated code consisting of 4 colors in 6 attempts. 
The UI for this game was written in Angular 18.2.0. This was my first attempt to write anything in Angular, in the end I think it turned out well.

Game is available here for playing : http://mastermind.somee.com/

Setup the project :
Install Node.Js ( I used Node: 18.20.4 )
Install Angular CLI (npm install -g @angular/cli)
Clone repository
Install dependencies (npm install)
Run project (ng serve)
